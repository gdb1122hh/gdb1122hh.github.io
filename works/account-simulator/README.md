# 🎵 抖音创作者模拟器

一个完整的账号发展模拟游戏，模仿抖音创作者中心的全套页面体验。

## 🚀 运行方式

直接用浏览器打开 `index.html` 即可，无需服务器、无需安装任何依赖。

推荐浏览器：Chrome / Edge / Safari 最新版

## 🎮 玩法说明

### 注册阶段
1. **选头像** — 20个 emoji 头像任选
2. **起名字** — 2-12个字符，可填个人简介
3. **选领域** — 8个创作方向：科技数码、美食探店、游戏电竞、生活日常、知识科普、搞笑娱乐、旅行探险、美妆时尚

### 模拟阶段

注册完成后进入主界面，**每3秒自动触发一个随机事件**，数据持续增长变化。

#### 六大页面

| 页面 | 功能 |
|------|------|
| 🏠 首页 | 数据看板（粉丝/获赞/播放/作品）+ 动态时间线 |
| 🎬 作品 | 所有作品卡片，含封面、标题、播放量、时长 |
| 📊 数据 | 播放趋势折线图、互动数据、粉丝画像、TOP3作品 |
| 💬 消息 | 系统通知、粉丝消息、合作邀请 |
| 🤝 合作 | 品牌商务合作管理（待确认/合作中/已结束） |
| ⚙️ 设置 | 切换速度、暂停/继续、重置账号 |

#### 事件类型

- 🔥 **正面事件**（高权重）：视频爆了、品牌合作、大V转发、上热搜、官方推荐、媒体采访、奖项提名...
- 📹 **日常事件**：日常更新、灵感爆发、设备升级、数据分析、粉丝互动、熬夜创作...
- ⚡ **负面事件**：流量下降、引发争议、创作瓶颈、恶意评论、疑似限流、版权警告...
- 🏆 **传奇事件**（稀有）：上电视、明星关注、海外走红、打破记录、出书邀请、平台签约...

#### 成就系统（18个）

百粉 → 千粉 → 万粉 → 十万 → 百万 → 千万
获赞过万 → 十万赞 → 百万播放
作品10/50/100 → 坚持30/100天
爆款制造机 → 浴火重生 → 经验丰富 → 社交达人

### 设置选项

- **速度切换**：极速(1.5s) / 正常(3s) / 慢速(6s)
- **暂停/继续**：暂停后事件不再触发
- **重置账号**：清空所有数据重新注册

## 💾 自动存档

每10秒自动保存到浏览器 localStorage，刷新页面后自动恢复进度。

## 🔧 技术细节

- 纯原生 JS，无任何框架依赖
- CSS 变量驱动主题色，模仿抖音暗色风格
- SVG 绘制趋势折线图
- localStorage 持久化存档
- 事件权重随机抽取，已触发事件进入冷却池
- 数据自然增长 + 事件脉冲增长双引擎

## ⚠️ 注意事项

- 必须通过 HTTP 或 file:// 直接打开（不支持某些严格CSP环境）
- 存档保存在浏览器本地，换浏览器/清缓存会丢失
- 首次打开如果看到注册页，说明是新游戏；如果有存档会自动跳过
