# 🦉 暗网回忆录 — ARG游戏

> 一个基于浏览器的沉浸式ARG（替代现实游戏），通过"论坛求助帖 → 网络时光机 → 网站存档解密"的三层结构，引导玩家逐步揭开一个消失网站的秘密。

## 🎮 快速开始

```bash
# 进入游戏目录
cd arg-game

# 启动本地服务器（必须，不能直接打开HTML）
python3 -m http.server 8765

# 浏览器访问
# http://localhost:8765/index.html
```

⚠️ **必须通过HTTP服务器运行**，因为游戏使用了iframe、fetch和相对路径引用。直接双击HTML文件会因CORS限制导致部分功能异常。

## 🧩 解谜流程

### 第一层：论坛页面 (`index.html`)
- 玩家看到楼主"迷路的夜猫"的求助帖
- 他找不到 `www.obsidian-archive.net` 这个网站了
- **4条评论**提供线索：
  - 深夜档案员 → 提供**网络时光机链接**（蓝色可点击）
  - 猫奴日记 → 提示"深层档案需要密钥"
  - 404NotFound → 技术角度分析 + 提示查看robots.txt
  - 狐狸的尾巴 → 暗示"真正重要的东西不会摆在明面上"

### 第二层：网络时光机 (`waybackmachine.html`)
- 搜索 `www.obsidian-archive.net` 显示3个快照
- 文件清单揭示网站结构（含锁定文件和隐藏文件）
- 玩家需要点击进入各快照查看内容

### 第三层：三个存档快照

#### 📅 2014年6月15日 — 初始版本
- 网站刚上线，内容简单
- **关键线索位置**：
  - `robots.txt` → `Key Fragment #1: O W L`
  - 首页HTML注释 → "The owl watches at midnight"
  - 首页白色隐藏文字 → "密钥第一部分是owl"

#### 📅 2015年9月3日 — 发展版本
- 网站内容丰富，新增留言板和深层档案
- **关键线索位置**：
  - 首页隐藏文字（白色） → "MIDNIGHT"
  - `guestbook.html` 留言#5 → CSS颜色代码 `#FFD700` (Gold)
  - `guestbook.html` 留言#7 → 坐标数据 + "先见、后见、常見"
  - `guestbook.html` 留言#6 → 分析推理过程
  - `catalog.html` → 深层档案列表

#### 📅 2016年2月28日 — 关站通知（搞笑版）
- 背景全是表情包，彩虹色标题动画
- **关键线索位置**：
  - 关站信中引用守夜人留言 → "猫头鹰在午夜醒来"
  - 隐藏段落（黄色文字） → "OWLMID" + 时间提示
  - 源代码注释 → 完整解密指引
  - `hidden-truth.html` → 终极真相页面

## 🔐 终极密码

| 片段 | 来源 | 内容 |
|-------|------|------|
| 第一部分 | 2014 robots.txt + 首页源码 | `OWL` |
| 第二部分 | 2015 首页隐藏文字 + 留言板 | `MID` (from MIDNIGHT) |
| **组合** | 6位字符 | **`owlmid`** |

**时间限制**：密钥仅在玩家本地时间 `00:00-01:00`（午夜时段）才生效。

**输入位置**：任一版本的 `vault.html` 页面

## 💡 隐藏彩蛋

- **Konami Code**：在键盘上依次输入 `O-W-L-M-I-D`，触发Toast提示
- **控制台信息**：打开DevTools可看到守夜人的留言
- **红色猫头鹰**：在 `vault-access.html` 右下角，点击触发随机消息
- **搞笑关站页**：标题每2秒变色，表情包可点击
- **源代码注释**：每个存档页面都有HTML注释形式的额外线索

## 🎯 设计理念

这个ARG借鉴了经典ARG游戏的设计原则：

1. **碎片化叙事** — 故事分散在20+个独立文件中，需要拼凑
2. **多层嵌套** — 论坛→时光机→存档→隐藏页面，层层深入
3. **元游戏元素** — 鼓励查看源代码、robots.txt等非传统位置
4. **渐进式难度** — 从明显的蓝色链接到需要推理的密码组合
5. **氛围营造** — 每个快照有不同的视觉风格和情感基调

## 📜 剧情概要

> 匿名管理员"守夜人"创建了一个收集稀有知识的网站"黑曜石档案馆"。他在全球埋藏了7个物理时间胶囊，并开发了一个能恢复任何已删除网络内容的工具。他将一切加密后消失，只留下散落在三个时光机快照中的线索。玩家通过解密找到密码，最终发现——所有"珍贵档案"都是伪造的诱饵，真正的宝藏是那个数据恢复工具。

## 🛠️ 技术说明

- 纯HTML/CSS/JS，零外部依赖
- 无后端、无数据库、无第三方API
- 所有"密码验证"在前端完成（这是为了游戏体验，非真实安全）
- 使用了CSS动画、Grid布局、Flexbox等现代特性
- 兼容Chrome/Firefox/Edge/Safari最新版本

## ⚠️ 已知限制

- 密码的"午夜时间限制"使用玩家本地时间
- 部分emoji在旧版浏览器中可能显示为方框
- 搞笑关站页的动画较多，低端设备可能卡顿
